# 三参考融合提示词

这是职责分离模板，不是固定逐字文案。填写实际图号、已有信息与用户要求，删除无依据的字段；只有两张参考时重排编号，不制造第三张图。

```text
任务：生成一张完整的人物成图，将指定人物、动作与穿搭融合在同一个自然场景中。

输入职责：
图 1 — 人物身份与画风参考。保留人物的五官、脸型、发型发色、肤色和体型比例；服装与姿势按下述参考替换。
图 2 — 姿势参考。采用动作、躯干方向、四肢位置、重心、支撑点和观察视角；不要迁移人偶线条、球形关节、面部十字线或图中模特的身份特征。
图 3 — 服饰参考。采用服装的颜色、版型、层次、材料、图案、配饰与鞋袜；不要迁移服装模特的脸、身体和站姿。

具体人物：[用户要求保留的特征，或仅以文字提供的人物描述]
动作：[可观察到的关键关节、支撑点与视角]
穿搭：[实际参考中可观察到的主要服装细节]
构图与背景：[用户要求；未指定时采用与动作适配的完整人物构图及简洁背景]
风格：[人物参考原有画风，或用户明确指定的风格]

让服装随身体姿势自然弯曲并产生合理褶皱。保持透视、肢体遮挡与接触关系一致。
只交付一幅人物图，不制作并排参考图、拼贴、说明文字、UI 或水印。
```

## 常见输入变化

- **人物只有文字**：先描述人物；将图 1 定义为姿势、图 2 定义为服饰。不要使用“保持图 1 的脸”等不存在的身份约束。
- **姿势只有文字**：将动作具体写出，包括左右、坐立、手的位置与观察方向；其余图片按实际角色编号。
- **服饰只有文字**：把主要单品、颜色和层次写清，不假称有服饰参考图。
- **人物图原本是半身**：保持可见身份与画风，合理补全全身；不要承诺不可见的身体特征与原人物完全一致。
- **脸被动作遮挡**：尊重姿势的自然遮挡，不为展示五官而强行扭头，除非用户要求调整视角。
- **用户要求换风格**：风格按用户指定，人物身份仍来自人物参考；不要把保持身份误写成必须维持原绘画媒介。
